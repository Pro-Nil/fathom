# @pentest-harness/dsh-session-folders

[English](README.md) | 中文

为每个会话在其工作区内分配独立文件夹，让同一工作区中的多个会话不再写入同一批文件。

会话文件夹为 `<工作区>/<folder>/<标题-slug>/`（默认 `<工作区>/sessions/<标题>/`）。终端（`bash`、`pwsh`）、文件（`read`、`write`、`edit`）和搜索（`glob`、`grep`）工具都从这里开始：命令在其中运行，相对路径以它为基准解析。会话记录的 `cwd` 仍是工作区本身，因此工作区归属、沙箱根目录和跨会话查询都不变，agent 仍可通过路径访问工作区的其他部分。

## 文件夹如何确定

- 文件夹在工具第一次需要时分配。如果会话目前只有根据首条消息即时生成的标题，服务会最多等待 `titleWaitMs`，等模型生成的标题。
- 文件夹内的 `.dsh-session` 文件记录所属会话 id。重启 harness 或重命名会话后，仍会找到并沿用同一个文件夹。
- 名称已被其他会话占用时，加数字后缀（`recon-2`）。
- 子 agent 或分叉会话（`parentSession`）与父会话共用文件夹。
- 服务启动前就已存在且没有文件夹的会话，继续在工作区根目录工作，进行中的任务不会被迁移。
- 没有标题服务时，文件夹名为 `session-<id 后 8 位>`。

分配文件夹后，运行时上下文会告诉模型它所在的文件夹。

## 配置

| 键 | 默认值 | 含义 |
| --- | --- | --- |
| `enabled` | `true` | 为每个新会话分配独立文件夹。 |
| `folder` | `sessions` | 上级文件夹，相对于工作区，必须位于工作区内。 |
| `titleWaitMs` | `15000` | 命名文件夹前等待模型生成标题的最长时间。 |
| `settings` | `false` | 注册 `session-folders` 设置命名空间，以便在 设置 → 插件 中修改 `enabled` 和 `folder`。 |

## 面向工具作者

`toolWorkdir(ctx, agent, root)`：服务已挂载且文件夹位于 `root` 内时返回会话文件夹，否则原样返回 `root`。在工具原本默认使用 `agent.session.header.cwd` 的地方调用它。
