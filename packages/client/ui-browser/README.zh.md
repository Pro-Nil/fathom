# @pentest-harness/dsh-client-ui-browser

[English](README.md) | 中文

Web 客户端的浏览器面板。它占用布局的 `aside` 列，位于会话右侧；会话列会收窄让出空间，而不是被遮挡。该列嵌入 [`dsh-browser`](../../browser/browser/README.zh.md) 在 `/browser/view` 提供的实时视图，用户看到的是智能体正在操作的同一组标签页，并可以在其中点击、输入和导航。

列头有四个按钮：重新连接视图、在独立窗口中打开、最大化或还原该列、关闭该列。列的左边缘是拖拽把手。在会话中，会话标题栏的工具区（Session log 旁边）有一个 **Browser** 按钮，通过 `ctx.layout.toggleAside` 打开或关闭该列；新会话界面没有标题栏，同一个按钮通过 `shell.overlay` 插槽浮在右上角。该列以窗口宽度的 45% 打开。

列关闭时面板不渲染任何内容，从而卸载 iframe、断开查看者并停止帧推送。它唯一的本地状态是重连计数；开关、宽度和最大化状态都属于布局 store。

## 模型体验

无，因为本包只贡献浏览器呈现；这里没有任何内容进入模型请求。

#### KV Cache 影响

无；本包不组装也不发送提供方请求。

## 已知限制与暂缓事项

- **不会自动打开** —— 智能体开始浏览时该列不会自行打开，需要用户点击开关。
- **几何状态是瞬时的** —— 与布局的其余部分一样，刷新后该列关闭并忘记宽度。
